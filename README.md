# Chama São Gabriel — MVP PWA

Marketplace local de gás e abastecimento para São Gabriel/RS.

## Teste

A versão atual é um MVP mobile-first com:
- Preço Agora e comparação por endereço;
- Mais barato, Recomendado e Mais rápido;
- carrinho multiproduto;
- pedido com preço protegido;
- aceite obrigatório da revenda;
- confirmação real de saída antes de exibir “A caminho”;
- PIN de entrega;
- cashback, clube e indicação;
- painel de revenda e convite para novos parceiros.

> Os nomes das revendas e preços atuais são demonstrativos até cadastrarmos os três parceiros reais.
